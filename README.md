# Резьба → Сверло / CNC Toolkit v3

Offline-first PWA для подбора отверстия под режущий метчик.

## Темы
- Blueprint Pro — тема по умолчанию
- Gold Premium
- Orange Industrial
- Neon Green CNC
- Brushed Steel

В настройках выбор темы применяется сразу и сохраняется на устройстве.

## Запуск
Статические файлы для GitHub Pages. Разместить содержимое этой папки
в корне ветки публикации. Открыть сайт по HTTPS, затем на iPhone выбрать
«Поделиться» → «На экран Домой».

## Подбор
Поддерживаются метрические резьбы (M) с обычным и мелким шагом.
Проверенные табличные диаметры отмечаются «Таблица», остальные — расчёт
по D − P. Значения ориентированы на режущие метчики; для раскатников,
ответственных допусков и необычных материалов пользоваться таблицами
производителя инструмента.

## Геометрия интерфейса
Верхняя шапка — обычный document flow, без position: sticky/fixed и blur.
Нижний dock — автономный fixed, bottom: 2px, width: 87%, height: 68px.
Safe Area используется для отступа контента, но не позиции dock.
