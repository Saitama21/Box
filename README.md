# CNC Copilot — unified offline PWA

Репозиторий используется как новый контейнер для объединения существующих CNC-приложений в одну offline-first систему.

## Текущий этап

- в корне развёрнута новая единая оболочка CNC Copilot;
- исходное приложение Box полностью сохранено в `legacy-box/`;
- старый Box пока не удаляется;
- модули подключаются по одному с сохранением их исходной логики и обязательной регрессией;
- GitHub Pages показывает новое приложение из корня.

## Порядок модулей

1. Режимы обработки / CNC Reference
2. Цеховые расчёты / CutCalc CNC
3. Укладка заготовок / Box
4. CNC Geometry
5. CNC Copilot / Напарник
6. Справочник G/M-кодов
7. Общий профиль станка
8. Общий рабочий процесс и результат

## UI-контракт

Нижний dock живёт независимо от Safari:

```css
position: fixed;
left: 50%;
transform: translateX(-50%);
bottom: 2px;
width: 87%;
height: 68px;
```

`safe-area-inset-bottom` используется только для нижнего запаса контента, но не для позиции dock.

## Offline-first

Критическая оболочка приложения кэшируется собственным Service Worker после первой полной загрузки. Cache namespace нового приложения изолирован от сохранённого legacy Box.

## Legacy Box

Оригинальные файлы Box находятся в `legacy-box/` и сохраняются до полной нативной интеграции модуля укладки и прохождения регрессии.
