# Резьба → Сверло — CNC Toolkit

Одноэкранная PWA под режущие метрические метчики с реалистичными растровыми иллюстрациями, выбором стандартного и мелкого шага и офлайн-режимом.

## Запуск

- Локальная проверка: `python3 -m http.server 8080` из папки проекта, затем `http://localhost:8080`.
- Публикация: загрузить содержимое папки в репозиторий GitHub, Settings → Pages → Deploy from a branch → main / (root). После публикации открыть URL GitHub Pages.
- iPhone: в Safari нажать «Поделиться» → «На экран Домой». После первого посещения опубликованного HTTPS-сайта приложение и изображения остаются в кэше Service Worker.
- Android: в Chrome открыть сайт → «Установить приложение» (название пункта может отличаться).

Всё автономно: без фреймворков, CDN, аналитики, API или внешних шрифтов. Файлы указаны относительными путями, поэтому работают в подпапке GitHub Pages.

## Инженерная оговорка

Сверла предназначены для **режущих**, не раскатных метчиков. В справочнике есть типовые табличные размеры и отдельно помеченные ориентировочные результаты `D − P`. Формула — распространённое приближение для выбора сверла, а не расчёт поля допуска. Для точного производства сверять ISO, допуск (например 6H/7H), материал и данные изготовителя метчика. Не использовать таблицу для резьбоформирующих метчиков.

## Состав

- `index.html` — единственный экран и модальные панели.
- `styles.css` — адаптивная UI-система; отдельный `position:fixed` dock, bottom:2px.
- `data.js` — размеры резьб и функция подбора.
- `app.js` — UX, настройки и расчёт.
- `assets/*.webp` — локальные реалистичные изображения.
- `manifest.webmanifest`, `sw.js` — установка и офлайн-кеш.
