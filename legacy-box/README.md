# Box PWA

Offline-first калькулятор укладки готовых деталей в промышленный пластиковый ящик.

## Что считает

Пользователь задаёт три значения:

- количество деталей в длину `X`;
- количество деталей в ширину `Y`;
- количество рядов по высоте `Z`.

Итог: `X × Y × Z`.

Приложение одновременно рисует три проекции прозрачного ящика: сверху, сбоку по длине и с торца по ширине. Сохранённые варианты хранятся в `localStorage` и работают офлайн.

## GitHub Pages

Публикация выполняется автоматически workflow-файлом `.github/workflows/pages.yml` после push в `main`.
