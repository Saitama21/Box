# Legacy Box

Не удалять до полной нативной интеграции модуля укладки в новое единое приложение и прохождения регрессии.

Корневая GitHub Pages-страница теперь принадлежит новому CNC Copilot; этот каталог нужен только как безопасный архив на время миграции.
